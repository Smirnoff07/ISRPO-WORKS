# Лабораторная работа №4: Написание Unit-тестов

## 1. Цели и задачи тестирования

Цель: Освоить методику модульного (unit) тестирования программного обеспечения с использованием фреймворка unittest в Python.

Задачи:
- Изучить принципы модульного тестирования
- Написать набор модульных тестов для функций вычисления площади и длины окружности круга
- Научиться запускать тесты и интерпретировать их результаты
- Интегрировать процесс тестирования в систему контроля версий Git

## 2. Описание тестируемого продукта

Тестируемый продукт представляет собой Python-модуль circle.py, содержащий две функции:

- area(r): возвращает площадь круга по формуле π * r²
- perimeter(r): возвращает длину окружности по формуле 2 * π * r

Требования:
- Функции должны корректно вычислять значения для неотрицательных входных данных
- Функции должны обрабатывать граничные случаи (нулевой радиус)
- Для вычислений должна использоваться точная математическая константа π

## 3. Область тестирования

Тестированию подлежат:
- Функция area(r) (площадь круга)
- Функция perimeter(r) (длина окружности)

В рамках тестирования проверяется корректность вычислений для различных значений радиуса.

## 4. Стратегия тестирования

Тип тестирования: Модульное (Unit) тестирование

Метод: "Чёрный ящик" (тестирование на основе спецификации функций)

Техника: Использование фреймворка unittest для создания и автоматизации тестовых случаев

Тестовые случаи:
- Для area:
  - test_zero_area: вычисление площади при нулевом радиусе
  - test_common_area: вычисление площади при стандартном радиусе
- Для perimeter:
  - test_common_perimeter: вычисление длины окружности при стандартном радиусе
  - test_zero_perimeter: вычисление длины окружности при нулевом радиусе

## 5. Критерии приемки

- Все написанные тестовые случаи выполняются без ошибок (Status: OK)
- Покрытие тестами включает как стандартные, так и граничные случаи входных данных
- Используется точное сравнение с математическими константами
- Код тестов зафиксирован в системе контроля версий Git

## 6. Ожидаемые результаты

- Отчёт о тестировании: Результат выполнения команды python -m unittest circle.py
- Отчёт о дефектах: В случае неудачи unittest генерирует Traceback с указанием ожидаемого и фактического значения
- Метрики качества: 100% успешное прохождение всех созданных тестовых сценариев
